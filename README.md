# WebPaste
if you need to copy a text from your other devices to another device; you can use this code that needs no additional library to install and only needs default python libraries.

> [!NOTE]
> This code is generated by AI.

# Usage
```
curl https://raw.githubusercontent.com/Ghoreish/WebPaste/refs/heads/main/WebPaste.py -O
python WebPaste.py
```
now open 127.0.0.1:8000

Also if you need to change the port only use the following command:
```
python WebPaste.py <Port>
```
Example:
```
python WebPaste.py 8899
```
